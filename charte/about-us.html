What each task needs

The details that matter.

Useful matches start with a clear scope, reliable task details and choice for both parties.

01 / Clear scope

Describe the work up front.

  • State what the task includes.
  • Add the location and schedule.
  • Add photos where useful.
02 / Local

Respect each travel area.

  • Set the task location early.
  • Consider travel distance.
  • Suggest relevant nearby tasks.
03 / Choice

Keep the worker in control.

  • Show the scope before a response.
  • Let workers choose whether to respond.
  • Allow work with different clients.
04 / Trust

Make decisions with clear information.

  • Describe expectations clearly.
  • Confirm terms before the task.
  • Collect feedback after each task.
