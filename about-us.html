Why Q DEAL?

Designed to work
alongside existing teams.

A team may need help organizing materials, resetting a store display or preparing an event. These clearly scoped tasks can be too short or too far away to fit traditional service workflows.

Q DEAL is intended to complement employees, specialist providers and staffing agencies, not replace them. Every task should set out its scope and terms, and workers should remain free to respond or decline.

A clear profile for relevant tasks

Skills, area and availability.

Self-employed workers will be able to describe their skills, travel area and availability. Guided profile setup is being considered to make task suggestions more relevant.

What each task needs

The details that matter.

Useful matches start with a clear scope, reliable task details and choice for both parties.

01 / Clear scope

Describe the work up front.

  • State what the task includes.
  • Add the location and schedule.
  • Add photos where useful.
02 / Local

Respect each travel area.

  • Set the task location early.
  • Consider travel distance.
  • Suggest relevant nearby tasks.
03 / Choice

Keep the worker in control.

  • Show the scope before a response.
  • Let workers choose whether to respond.
  • Allow work with different clients.
04 / Trust

Make decisions with clear information.

  • Describe expectations clearly.
  • Confirm terms before the task.
  • Consider feedback after each task.
